Registrar Información en el Sistema

Inicia registrándote como usuario o centro de acopio para interactuar con el sistema.

1. Registro de Nuevo Consumidor (Completo)

Completa todos los campos para crear tu cuenta de consumidor.

**Tipo de Usuario:** Consumidor (`tipo_usuario_id = 1`). El sistema autogenerará tu `usuario_id`.

2. Registro de Centro de Acopio

Registra tu centro de acopio para recibir productos dispuestos.

**Tipo de Usuario:** Centro de Acopio (`tipo_usuario_id = 2`). El sistema autogenerará su `usuario_id`.

3. Registrar Nueva Compra

Ingresa tus datos básicos. El sistema validará tu cuenta o la creará (como Consumidor) antes de guardar la compra.

4. Registrar Disposición Final

Esto vincula la disposición con la compra (compra_id).
Muestra el nombre, pero guarda el ID del Centro.
